# Mapping context

What the osu! community writes about making beatmaps, gathered so every session starts with it.
Each file summarises sources **in our own words** and links them; nothing here is copied text
(the osu! wiki is CC BY-NC 4.0, forum posts belong to their authors). Read the source before
relying on a detail. Product principles live in `docs/mapping-principles.md`.
The old study scripts under `ml/rhythm` are historical research; their dataset is no longer
required or retained as part of the active workflow.

| File | What it covers |
|---|---|
| [01-ranking-criteria.md](01-ranking-criteria.md) | Official rules per difficulty: rhythm, overlap, sliders, spinners, AR/OD/HP/CS, timing, kiai |
| [02-rhythm-and-layers.md](02-rhythm-and-layers.md) | Which sounds to map, layers, active vs passive objects, overmapping |
| [03-emphasis-spacing-contrast.md](03-emphasis-spacing-contrast.md) | Emphasis, intensity, contrast, phrases, spacing techniques |
| [04-flow-and-patterns.md](04-flow-and-patterns.md) | Flow, angles, repetition, jumps, formations, visual consistency |
| [05-sliders-spinners-combos.md](05-sliders-spinners-combos.md) | Slider techniques and velocity, spinner placement, new combos |
| [06-ai-mapping-projects.md](06-ai-mapping-projects.md) | Mapperatorinator, osuT5, osu-diffusion: designs and lessons |
| [07-study-queue.md](07-study-queue.md) | Material not read yet (videos, long threads) and what to look for |
